# FornaxTech US Careers

**Discover Opportunities. Build Your Future.**

FornaxTech US Careers is a candidate-facing careers portal for exploring technology and leadership opportunities in the US market. Candidates can browse roles, search by title or skills, filter opportunities, and contact the recruiting team to express interest.

## Overview

This repository contains the standalone, mobile-friendly careers website for FornaxTech.

### Key features

- Responsive layout for desktop, tablet, and mobile devices
- Searchable opportunity listings
- Filters for work mode and job category
- Individual **Express Interest** forms for each opportunity
- Prefilled email applications addressed to **sachin.r@fornaxtech.com**
- Candidate fields for name, email, phone, location, LinkedIn profile, relevant experience, US work authorization, and a brief introduction
- Clear notice that draft opportunity details must be confirmed

## How candidate applications work

1. A candidate selects an opportunity and clicks **Express Interest**.
2. The candidate completes the inquiry form.
3. The portal opens the candidate's default email application with the role and entered details prefilled.
4. The candidate attaches their latest resume and sends the email to **sachin.r@fornaxtech.com**.

**Application email:** `sachin.r@fornaxtech.com`

This is an email-based workflow. The static website does not upload, store, or process resumes or candidate applications. The candidate must review the email, attach their resume, and send it.

## Run locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Test the search, filters, and **Express Interest** form.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for GitHub Pages to publish the site.

The public website URL will be shown in the repository's **Pages** settings.

## Updating opportunities

Before publishing or updating a job listing, verify:

- Whether the role is currently open
- Approved job title and complete job description
- Client disclosure permissions
- Location and work arrangement
- Employment type and travel expectations
- Compensation range and benefits, where approved
- Required technical skills and experience
- Work authorization and sponsorship requirements

When a role is no longer available, update or remove its listing promptly. Do not represent a draft listing as a confirmed vacancy.

## Customization

The current portal is a standalone HTML, CSS, and JavaScript website. Job cards, styling, and application form behavior are maintained in `index.html`.

For future versions, the portal can be extended with a job-management interface, a database-backed application workflow, and role status controls. Those capabilities are **not included** in this static version.
